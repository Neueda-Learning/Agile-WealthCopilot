02 / 12

The user problem

Trust Concern

Records

Buys, sells, dates and fees often live in notes or spreadsheets, with no timeline validation.

Prices

Live quotes can be slow or unavailable, while users still need a stable portfolio view.

Questions

Users want plain-language answers, but should not surrender control to an opaque agent.

What users need: one explainable source of truth. What we do not build: brokerage, prediction or investment advice.

The deterministic core

Portfolio Calculation

Transaction timeline

BUY → SELL

Positive quantities, USD-only v1, and no sale beyond holdings at that date.

Average-cost engine

quantity × average cost

Replays the full timeline after create, edit or delete.

Explainable output

Value + P&L

Holdings, cost basis, realized and unrealized performance.

Safe edit: earlier changes re-check later SELLs
Consistent: one engine serves UI, API and AI
Auditable: every number traces to transactions
05 / 12

Why this core is stronger

Core Principles

The portfolio remains useful even when the LLM or market-data provider is unavailable.
One source of truth All channels reuse the same service-layer rules.
Safe correction Edit and delete revalidate the entire investment timeline.
Honest trade-offs USD-only and average cost keep v1 coherent rather than half-solving FX and tax lots.

Trust & delivery evidence

Security Controls

01 Identity

BCrypt passwords and stateless, short-lived JWT authentication.

02 Database isolation

Every user-owned repository query is scoped by the authenticated user ID.

03 Existence privacy

Cross-user access behaves as not found, avoiding disclosure that a resource exists.

04 Repeatable quality

JUnit, Mockito, Testcontainers MySQL, Flyway migrations and an external health surface.

10 / 12

AI feature 2

AI Guardrails

✓

Cans

  • Summarize portfolio value, cost basis and P&L.
  • Explain personal holdings and transaction history.
  • Retrieve cached quotes and recent stock news.
  • Create transaction drafts for user review.
  • Answer follow-ups within the current conversation.
×

Can’ts

  • Predict prices or guarantee investment returns.
  • Recommend what the user should buy or sell.
  • Execute trades, transfer funds or move assets.
  • Write portfolio data without explicit confirmation.
  • Access another user’s records or bypass authentication.
